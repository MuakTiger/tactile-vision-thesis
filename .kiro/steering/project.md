# 프로젝트 공통 맥락 (모든 세션 자동 포함)

## 정체성

단안 깊이 추정 기반 24구역 촉각 디스플레이를 이용한 실시간 시각-촉각 감각 대체 장치.
을지대학교 의료공학과 학부 졸업논문 + 창업 아이템으로 동시 진행 중.

카메라 영상에서 추정한 깊이를 24개 서보 구동 핀의 Z축 돌출량으로 변환해,
사용자가 전방 공간의 깊이 분포를 손바닥 위의 입체 지형으로 지각하게 한다.

## 파이프라인

```
USB 웹캠 (MJPEG, 720p, V4L2)
 │
 ▼
NVIDIA Jetson Orin Developer Kit (Python, Miniconda)
 ├─ Depth Anything V2 ViT-S, TensorRT .engine → 깊이맵
 ├─ 가로 6 × 세로 4 = 24구역 평균 깊이 산출
 └─ UART 115200bps ASCII → "GRID:v0,...,v23\n"
       │
       ▼
Raspberry Pi Pico (RP2040, arduino-pico 코어, C++)
 ├─ I2C → PCA9685 #1 (0x40) → SG90 × 12 (1~2행)
 └─ I2C → PCA9685 #2 (0x41) → SG90 × 12 (3~4행)
       │
       ▼
랙앤피니언 3D 프린팅 기구부 → Z축 핀 돌출
```

## 그리드 배치

```
[ 0][ 1][ 2][ 3][ 4][ 5]  1행 ┐
[ 6][ 7][ 8][ 9][10][11]  2행 ┴→ PCA9685 0x40, 채널 0~11
[12][13][14][15][16][17]  3행 ┐
[18][19][20][21][22][23]  4행 ┴→ PCA9685 0x41, 채널 0~11
```

- Depth Anything V2는 disparity 기반이므로 **값이 클수록 가깝다**
- 가까울수록 해당 구역 핀이 더 높이 돌출
- 2초 무통신 시 홈 복귀 failsafe 동작

## ⚠️ 저장소가 두 개로 갈라져 있다

이것이 현재 가장 중요한 리스크다. 코드나 스펙을 언급할 때 **어느 저장소인지 반드시 명시**할 것.

| | `device/` | `device-dev/` |
|---|---|---|
| 리모트 | `tactile-vision-device` | `tactile-vision-device-**dev**` |
| HEAD | `3f17469` | `fd289e6` |
| 객체 인식 | **없음** (깊이만) | YOLO 통합 + 위험도 3단계 + jittering |
| 패킷 | `GRID:v0,...,v23` | `GRID:...\|OBJ:idx,danger` |
| `software/main.py` | 기준 | +431줄 차이 |
| Pico 펌웨어 | `main.cpp` | `main.cpp` + `main_pico_v3.cpp` (미커밋) |
| 하드웨어 STL | **있음** (5개) | 없음 |
| 논문 초안 | 없음 | `thesis_draft.md` (834줄, **구버전 — 사용 금지**) |

**논문이 인용하는 것은 `device/`의 `3f17469`이다.** 논문 본문에 YOLO 언급은 0건이다.
따라서 `device-dev/`의 YOLO 기능은 현재 논문 범위 밖이며, 논문에 쓰려면
저장소 통합과 실측이 선행되어야 한다. 이 결정은 `FACTS.md`에 기록한다.

`device-dev/`에는 미커밋 파일이 있다 (`main_pico_v3.cpp`, `skku_sagemaker.html`).

## FACTS.md 규약 — 세션 간 정보 교환의 유일한 공식 경로

Kiro 세션은 대화 컨텍스트가 서로 격리된다. 논문 세션과 소프트웨어 세션은
서로의 대화를 볼 수 없다. **파일에 쓰이지 않은 정보는 존재하지 않는 정보다.**

따라서:

1. 어떤 세션이든 **검증된 사실을 확정하면 즉시 `FACTS.md`에 기록**한다.
   근거(실측/데이터시트/코드 경로+줄번호)와 날짜를 함께 적는다.
2. 어떤 세션이든 **해결해야 할 항목을 발견하면 `FACTS.md`의 미해결 목록에 추가**한다.
3. 세션 시작 시 `FACTS.md`를 읽고, 종료 전 갱신한다.
4. `FACTS.md`에 없는 수치를 논문에 결과로 쓰지 않는다.

## 표기 규약 (논문·FACTS 공통)

| 표기 | 뜻 |
|---|---|
| 〔측정필요〕 | 벤치 실험으로 반드시 실측해야 하는 값 |
| 〔확인필요〕 | 데이터시트·실물 계측·원자료로 검증해야 하는 값 |
| 〔데이터 수집 예정〕 | 실험 미수행. 표·그림 틀만 존재 |
| 〔선택〕 | 범위 축소 시 제외 가능 |
| *(산정치)* | 이론식 계산값. **실측값 아님.** 반드시 실측으로 교체 |

## 금지 사항

- 실측되지 않은 수치를 실측값처럼 서술하지 않는다. 반드시 *(산정치)* 를 유지한다.
- 코드를 읽지 않고 시스템 동작을 논문에 단정하지 않는다.
- `device/`와 `device-dev/`의 내용을 출처 표시 없이 섞지 않는다.
- `mortality-app/`은 이 프로젝트와 무관하다. 참조하지 않는다.
