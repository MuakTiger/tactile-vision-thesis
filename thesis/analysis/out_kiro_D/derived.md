## 반응 시간 구성

- 프레임 대기 + 처리: 34.8 + 68.8 = 103.6 (프레임별 합의 평균 103.6)
- 전송→시작 + 이동: 116.3 + 163.8 = 280.1 (도착 평균 280.1)
- 장면 변화 → 시작(평균 합): 103.6 + 116.3 = 219.9 ms
- 장면 변화 → 도착(평균 합): 103.6 + 280.1 = 383.7 ms
- 비율: 처리 27.0%, 구동 73.0% (반올림 27% / 73%)
- 시작 시간 범위 폭: 174.1 ms; 시작 평균 − 박자 대기 기대값 100 ms = 16.3 ms
- 속도 제한 계산: 끝→끝 175 ms, 5→95% 157.5 ms
- 1.2 m/s 보행 거리: 도착 평균 0.46 m, p95 합산 최대 0.62 m
- 확인 화면을 켠 실행의 실제 갱신: 2회/s ÷ 판별 실행 비율 = 9.4 fps
- 장면 판별 시간 p95(실행 프레임): 22.4 ms
- 시행 수: 17 (올림 8, 내림 9)
