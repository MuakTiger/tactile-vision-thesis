## 1. 이 연구를 한 문장으로 (핵심 주장)

> 웹캠과 서보 24개로 만든 손바닥 핀 촉각 장치는 장면별 거리 보정(실내 −0.44 m, 실외 착용 높이 기반 '땅 기준 환산')을 더하면 측정한 모든 사진(실내 0.5~4 m, 실외 1~8 m)에서 거리를 핀 높이 ±1단계 안으로 표시하고, 장면 변화부터 핀 도착까지 평균 약 0.38초(17회 모두 1초 안)에 전달한다. (벤치 측정, 사람 대상 시험 전)

뒷받침하는 두 가지 발견:
- 가장 큰 오차는 모델 자체가 아니라 **카메라 조건**에서 왔다. 실외 metric 모델은 보정 없이 MAPE 518.5%(1 m 상자를 평균 8.82 m로 봄)였고, 모델을 바꾸지 않고 착용 높이로 환산하자 21.1%가 되었다. (§1.8, §1.9)
- 지연의 약 4분의 3(280.1 / 383.7 ms)은 영상 처리가 아니라 **핀 구동(박자 대기 + 서보 이동)**에서 생긴다. 측정 전에 세운 가설(§2.2 H-I1)과 같은 방향이다. (§1.10)

**D판의 관점.** 처음 보는 사람에게 이 프로젝트는 "장치를 만들었고, 정보가 지나가는 길(카메라 → 거리 → 단계 → 핀)을 네 군데서 쟀다"로 보인다. 이것을 의료기기 개발의 **설계 검증(요구사항 대비 시험)**으로 묶으면, 보행 결과 없이도 질문 → 방법 → 결과 → 판정이 끝까지 이어지는 논문이 된다. 사용자 시험(보행)은 다음 단계로 분명히 떼어 낸다.

## 2. 기여

1. **장치**: 범용 부품(웹캠, Jetson Orin Nano, Pico, SG90 24개, 3D 프린팅 랙·피니언)으로 거리(m)를 로그 눈금 8단계 핀 높이로 바꾸는 양손 손바닥 24핀 장치를 만들고, 표시 범위(실내 0.5~8 m, 실외 0.5~20 m)·핀 박자(0.2 s)·스트로크(9.0 mm)를 하나의 설계 규칙으로 묶었다. (§1.6, §1.9, §1.11)
2. **거리 보정**: 착용 높이(0.70 m)에서 실외 metric 모델이 땅까지 거리를 3.11~3.69배 멀게 보는 것을 확인하고, 학습 카메라 높이·화각 차이로 계산한 3.50배와 맞음을 보였다. 상대 깊이를 카메라 높이로 환산하는 땅 기준 방법으로 실외 MAPE 518.5% → 21.1%, ±1단계 0% → 100%가 되었다. 상자 거리로 맞춘 값이 없어 120장 전체가 검증 자료다. (§1.9)
3. **시간 분해**: 장면 → 핀 시간을 처리(로그 7,894프레임)와 구동(슬로 모션 17회)으로 나누어 재고, 이동 시간 163.8 ms가 펌웨어 속도 제한 계산 157.5 ms와 맞음을 보였다. (§1.10)
4. **기구 보정 절차**: 24핀 영점의 조립 편차(SD 2.20 mm, 최대 4.0단계)를 재고, 보정값을 장치 기본값으로 고정하는 절차를 만들었다. (§1.11)
5. **검증 틀**: 요구(R1~R6) → 측정 → 판정을 한 표로 잇는 검증표로 정리했다. 측정에 빠진 부분도 표에 함께 적는다.

### 6.1 Ⅰ. 서론 (문단 5개, 소절 없음)

1. **배경**: 2020년 실명 인구 약 4,330만 명[GBD 2021]. 흰지팡이는 발 앞 땅을 살피지만 머리·가슴 높이 장애물 충돌 사고가 보고된다[Manduchi]. 전자 보행 보조기가 많이 제안되었고[Dakopoulos, Elmannai], 소리 출력은 주변 소리를 듣는 데 방해가 될 수 있어 촉각 전달도 연구되어 왔다.
2. **촉각 감각 대체의 흐름**: 카메라 영상을 등의 400점 자극으로 바꾼 TVSS[Bach-y-Rita 1969], 다른 감각으로 들어온 공간 정보를 뇌가 학습한다는 관점[Bach-y-Rita & Kercel, Merabet], 혀 전기 자극 장치의 기능 평가[Grant], 소리 변환[Meijer], ToF 거리 센서 + 진동 장치[Katzschmann]. 핀 높이(형상) 디스플레이는 자극이 멈춰 있어 손으로 다시 확인할 수 있고, 정적 눌림은 SA-I 수용기가 담당한다[Johnson, Vidal-Verdú].
3. **문제 제기**: 웹캠 하나로 거리를 얻는 단안 깊이 추정이 발전했다[DA V2]. 그러나 (가) 미터 거리를 내는 단안 모델은 학습 카메라와 초점거리(화각)가 다르면 배율이 틀릴 수 있다고 지적된다[Metric3D]. 이 장치의 카메라는 학습 자료의 차량 카메라[KITTI, VKITTI2]보다 낮은 0.70 m에 있고 화각도 다르다(높이 효과는 이 논문의 측정으로 보인다 — Ⅳ¶1). (나) 저가 서보 24개로 핀을 움직이면 박자 대기·속도 제한·조립 편차가 생기므로, 화면의 거리가 손바닥 높이로 '언제, 얼마나 정확히' 바뀌는지 따로 재야 한다.
4. **실마리**: 카메라 높이를 알면 화면 아래 땅까지의 거리를 기하로 계산할 수 있어, 차량 단안 주행 거리 추정에서 배율을 정하는 데 쓰였다[Song & Chandraker, Zhou]. 착용형 장치는 카메라 높이가 착용 위치로 거의 정해지므로 같은 생각을 쓸 수 있다.
5. **목적과 질문**: 사람 대상 시험에 앞서 장치가 설계대로 동작하는지(설계 검증)를 묻는다. (1) 영상 처리가 핀 박자(5 Hz)보다 빠른가. (2) 표시 단계가 실제 거리 단계와 ±1단계 안에 드는가 — 깊이 모델을 그대로 쓸 때와 장면별 보정을 했을 때. (3) 장면 변화 → 핀 도착이 1 s 안인가, 지연은 어디서 생기는가(가설: 처리보다 구동 쪽이 크다). (4) 24핀 영점 편차가 1단계 안인가. 보행 효과는 다루지 않는다고 한 문장으로 밝힌다.

**2.4 분석 및 판정 기준** ([표 2])
- MAPE = 평균(|추정 − 실제| / 실제) × 100. 표시 단계 오차 Δ = 7 × |ln(추정/실제)| / ln(d<sub>far</sub>/0.5)(반올림 전, d<sub>far</sub> 안쪽). '단계 일치' = 반올림한 단계가 같음, '±1단계' = 반올림한 단계 차가 1 이하. 단계는 필터 없이 계산한다. (level_budget.py 설명, calib_compare.md)
- 장소 교차 = 한 장소로 정한 보정값을 다른 장소에 적용. 땅 기준 환산은 사진에 맞춘 값이 없으므로 120장 모두 검증 자료다.
- 같은 장소·거리의 5장은 같은 장면이라 독립이 아니다 → 장소 × 거리 12묶음 평균으로 비교: 묶음 MAPE 차 평균, 부트스트랩 10,000번 95% 구간, 정확 윌콕슨 부호순위 검정(양측, 유의 수준 0.05). 사진 단위 검정은 독립 가정이 맞지 않아 쓰지 않는다. (ground_scale.py: N_BOOT = 10000, seed 0, `method="exact"`)
- 반응 시간과 핀 영점은 기술 통계(평균·SD·중앙·범위·p95).

### 6.4 Ⅳ. 고찰 (문단 6개, 각 문단 첫머리에 굵은 짧은 제목, 번호 소절 없음)

1. **가장 큰 거리 오차는 카메라 조건에서 왔다.** 실외 모델의 과대 추정 3.11~3.69배가 학습 카메라 높이(1.65 m, KITTI 값 가정)·초점·세로 화소 차이로 계산한 3.50배와 맞는다 → metric 모델이 학습 카메라의 기하를 함께 배운 것으로 볼 수 있다[Metric3D, KITTI, VKITTI2]. 배율 k가 장소마다 달라(0.257 / 0.157) 하나의 k로는 고칠 수 없고(63.2%), 착용 높이를 '자'로 삼아 프레임마다 배율을 정하면 21.1%가 된다 — 차량 연구의 땅 기준 배율과 같은 생각을 착용형에 옮긴 것[Song & Chandraker, Zhou]. 실내 모델은 거리와 거의 상관없이 0.4~0.5 m 멀게 보는 '더하기' 모양이라 + b(9.5%)가 × k(18.0%)보다 나았다.
2. **왜 상대 깊이를 그대로 쓰지 않았나 ('같은 거리 = 같은 높이')**: 사진마다 최솟값~최댓값으로 늘리는 상대 방식에서는 상자가 0.5 m에 오면 같은 땅의 값이 0.60 → 0.34로 바뀌었고(실내 1), 0.5 m와 1 m가 구분되지 않았다(§1.9 상대깊이 탐색). 미터 거리로 바꿔 쓰면 장면이 바뀌어도 같은 거리는 같은 높이가 된다.
3. **남은 거리 오차와 가정**: 주차장 31.2% 대 산책로 10.9%. 기울기 1°나 높이 5 cm가 틀리면 MAPE가 약 4~6%p 바뀐다(3.2 민감도 값) → 걷는 중 흔들림·땅 경사가 남은 오차의 후보(확인 안 함). 땅이 화면 아래에 보여야 하고(맨 아래 줄 땅 1.82 m, 1 m 앞 32 cm 미만 물체는 화면 밖), 실외 8 m 넘는 거리(d<sub>far</sub> 20 m 범위의 8~20 m)는 검증하지 않았다. 실내 −0.44 m 때문에 바닥이 약 1.4 m로 나와 맨 아래 줄이 약 1단계 높을 수 있다. 묶음 윌콕슨 p = 0.092 — 장소 2곳뿐이라 근거는 '시사' 수준이고, 같은 사진으로 방법을 고르고 검증했으므로 새 장소 사진으로 다시 확인해야 한다. (§1.9)
4. **지연은 구동 쪽이 대부분이다.** 처리 103.6 ms 대 구동 280.1 ms(73%). 시작 시간의 폭(약 174 ms)은 0.2 s 박자 대기와 맞고(평균 대기 기대값 100 ms를 빼면 서보 반응 약 16 ms), 이동 163.8 ms는 속도 제한 계산 157.5 ms와 맞는다 → 측정 전 가설(처리보다 구동이 크다)과 같은 방향. 계산상 박자 대기(기대값 100 ms)만큼 줄일 여지가 있다(후속 과제, 부드러운 움직임·진동 시점과의 균형은 확인 필요). 빠진 지연: 카메라 내부·화면 표시(하한), 시간 필터가 만드는 늦음. 1.2 m/s로 걸으면 평균 도착까지 약 0.46 m, p95 합산 최대 0.62 m를 걷는다. 1.2 m/s는 성인의 편한 보행 속도(1.27~1.46 m/s[Bohannon])보다 조금 느린 값이다. (§1.10, out_level)
5. **핀 영점 보정은 꼭 필요했다.** 보정 전 영점 오차(절댓값 평균 1.25단계, 최대 4.0단계)가 보정한 거리 오차(|Δ| 0.19~0.35단계)보다 크다 → 칸별 보정 없이는 기구 오차가 표시 오차를 지배한다. 피니언 이 하나 ≈ 4.19 mm(65 tick)라 큰 오차는 조립 때 맞물림이 한 칸 어긋난 것으로 설명될 수 있다(확인 안 함). 4열 네 칸이 모두 들어가 있었다(−1.61 ~ −3.55 mm, 원인 확인 안 함). 보정 뒤 잔여 오차는 재지 않았다(조정 걸음 0.32 mm = 0.25단계). (§1.11, out_level)
6. **이 결과가 말하지 않는 것과 후속 연구.** 한계: 사람 대상 시험 없음(1.29 mm 단계를 손바닥이 구별하는지, 24핀이 보행에 도움이 되는지), 정지 사진·장소 2곳씩·표적 1종, 장면 판별 정확도·실제 전환 미평가, 위험 진동 1°가 서보가 반응하지 않는 범위 안일 수 있음(미확인), Pico 전원이 끊기면 서보가 힘을 잃어 소프트웨어로 핀을 내릴 수 없음, 초점거리는 제조사 사양에서 계산. 후속: 정지 장애물 감지 시험 → 손바닥 높이 구별 시험으로 단계 수 결정 → 연구 윤리 심의를 거친 보행 시험(1인 → 여러 명), 카메라 보정과 기울기 측정, 전원 차단 시 핀을 내리는 하드웨어 대책.

### 6.5 Ⅴ. 결론 (한 문단, 4~5문장)

만든 것(24핀 손바닥 장치 + 장면별 거리 보정) → 잰 것과 핵심 수치(실외 21.1%, 실내 9.5%, 보정 후 ±1단계 100%, 평균 383.7 ms·17회 모두 1 s 안, 영점 SD 2.20 mm) → 교훈(카메라 조건 보정과 칸별 영점 보정이 결정적, 지연은 구동 쪽) → 다음 단계(사람 대상 시험). 새 숫자는 넣지 않는다.

## 11. 작성 규칙

**양식·생성기(`build_docx.py`) 문법** — 이 문법 밖의 것은 docx에 깨져 들어간다.
- 맨 앞 `>` 줄(작성 메모)만 docx에서 빠진다. 본문 중간에 `>`나 HTML 주석(`<!-- -->`)을 쓰지 않는다(그대로 찍힌다). 숫자 근거는 원고가 아니라 근거표에 적는다.
- 머리 정보: `---` 사이에 `title_ko:`, `title_en:`, `authors_ko:`, `authors_en:`.
- `## 요약`, `## Abstract` → 본문에 `**목적:**` `**방법:**` `**결과:**` `**결론:**`(영문 `**Purpose:**` `**Methods:**` `**Results:**` `**Conclusion:**`), 마지막 줄 `**주제어:** …` / `**Keywords:** …`.
- 장 제목은 양식 글자 그대로: `## Ⅰ. 서  론`, `## Ⅱ. 연구 방법`, `## Ⅲ. 결  과`, `## Ⅳ. 고  찰`, `## Ⅴ. 결  론`, `## 참고문헌`. 소절은 `### 2.1 연구 대상` 형식.
- 그림: `![[그림 1] 설명](figures/D/fig_D_system.png){width=7.2}` (경로는 md 파일 위치 기준, 너비 7.4 cm 이하).
- 표: `[표 1] 제목` 줄 바로 다음 줄부터 `|` 표(빈 줄 없이). 첫 칸이 `§ `로 시작하는 줄은 가로로 합친 구분 줄. 표 바로 뒤 `주:`로 시작하는 문단은 표 주석.
- 글 안: `**굵게**`, `*기울임*`, `<sub>아래</sub>`, `<sup>위</sup>`, `〔빈칸〕`(노란 형광). **LaTeX(`$…$`)는 지원하지 않는다** → 수식은 유니코드(×, −, ≤, ≈, ln)와 `<sub>`로 쓴다(예: d<sub>far</sub>).
- 참고문헌: `## 참고문헌` 아래 한 줄에 하나 `[n] …`, DOI는 `https://doi.org/…` 주소로.
- 번호: [그림 1]·[표 1]처럼 전체 일련번호(장 단위 '표 3-1'은 옛 규칙). 본문에서 처음 언급하는 순서대로 번호를 매기고, 모든 표·그림을 본문에서 한 번 이상 부른다.

**문체** — 쉬운 학술 한국어.
- 평서형 "~하였다/~이다". 한 문장에 한 가지 내용, 대략 60자 이내.
- 용어는 처음 나올 때 풀어 쓴다: MAPE(평균 절대 백분율 오차), p95(95번째 백분위), tick(서보 펄스 단위, 핀 0.0646 mm), 표시 단계(핀 높이 0~7단계), 장소 교차(한 장소로 정한 값을 다른 장소에 적용).
- 띄어쓰기·단위: `24칸`, `8단계`, `9.0 mm`, `0.2 s`, `383.7 ms`, `14.4 W`, `21.1%`, 퍼센트 포인트는 `%p`. 소수 자리는 출처 그대로.
- Ⅲ(결과)에는 "때문", "~로 보인다", "시사", "의미한다" 같은 해석 말을 쓰지 않는다. 비교와 기준 대비만.
- 피할 표현: "절대 거리", "실현 가능성을 입증", "요구사항을 만족하여 실용 가능", "최초", "완벽", "획기적". '판정'은 "측정 범위에서 기준 안"처럼 조건을 붙인다.
- 논문 안에 'FACTS', 'HANDOFF', 세션·도구 이름, 파일 경로를 쓰지 않는다(코드 저장소 인용 [n]은 예외).

import re, pathlib
T = pathlib.Path("/Users/skku_aws3_08/Documents/20260917/thesis-repo/thesis")
md = (T / "졸업논문_D_처음부터쓴판.md").read_text(encoding="utf-8")
ev = (T / "졸업논문_D_근거표.md").read_text(encoding="utf-8")

unit = r"(?:%p|%|ms|mm|m|s|fps|W|px|tick|°|장|회|칸|단계|배|번|줄|열|행|Hz|kHz)"

print("근거표에 없는 값:", [n for n in nums if n not in ev])
for kind in ("그림", "표"):
    seen = []
    for n in re.findall(r"\[" + kind + r" (\d+)\]", body):
        if int(n) not in seen: seen.append(int(n))
    print(kind, seen, "OK" if seen == list(range(1, len(seen) + 1)) else "순서 확인")
first = []
for grp in re.findall(r"\[(\d+(?:\s?[,–-]\s?\d+)*)\]", body):
    for part in re.split(r",\s?", grp):
        a, _, b = part.partition("–") if "–" in part else part.partition("-")
        for c in (range(int(a), int(b) + 1) if b else [int(a)]):
            if c not in first: first.append(c)
nref = len(re.findall(r"^\[\d+\] ", md.split("## 참고문헌")[1], flags=re.M))
print("인용 순서", "OK" if first == list(range(1, len(first) + 1)) else first, "/ 인용", len(first), "목록", nref)
EOF
